Network troubleshooting

Quick workflow for diagnosing local connectivity, DNS and gateway issues.

View checklist
  1. Check the cable or Wi-Fi connection and whether other users are affected.
  2. Check the assigned IP address and default gateway.
  3. Test gateway reachability, then DNS resolution. Document results and escalate if needed.
02

Windows workstation setup

Checklist for configuring user accounts, security, updates and office tools.

View checklist
  1. Confirm the approved device and user account.
  2. Install approved updates and applications.
  3. Verify endpoint protection, backup policy and least-privilege access.
03

Printer support

Common steps for queues, drivers, IP configuration and spooler problems.

View checklist
  1. Confirm power, paper and any device error.
  2. Verify connectivity and the selected printer.
  3. Inspect the queue and approved driver; record the fix in the ticket.
04

User account recovery

Safe reset workflow with identity verification and access restoration.

View checklist
  1. Verify the requester using the organization’s approved process.
  2. Use the authorized account recovery workflow; never ask for an existing password.
  3. Confirm access and record the resolution without storing credentials.

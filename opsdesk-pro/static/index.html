01 / CONNECTIVITY

Network troubleshooting

  1. Confirm who is affected and when the problem started.
  2. Inspect the connection and assigned IP configuration.
  3. Test gateway reachability, then DNS resolution.
  4. Document the results and escalate with evidence.

02 / IDENTITY

Account recovery

  1. Verify identity using the approved organizational process.
  2. Use the authorized recovery workflow.
  3. Never request or store an existing password.
  4. Confirm access and document the outcome.

03 / DEVICES

Workstation onboarding

  1. Register the asset and department.
  2. Install approved software and security updates.
  3. Apply least-privilege access.
  4. Verify backups and user access before handover.
